# AptechExam
android app of aptech exams of CPISM, DISM and ADSE courses

## Description
This app aim to help studen in aptech computer education to get sucess in exam by orgnizing all the exam of the certificate metioned below.

All exams for these three aptech courses:

* Certificate of Proficiency in Information System Management (CPISM).

* Diploma in Information System Management (DISM).

* Advanced Diploma in Software Engineering (ADSE).

## Building from Source

### Prerequisites
- JDK 11 (Gradle 7.0.2 requires Java 11)
- Android SDK (API 31, Build Tools)

### Build Debug APK
```bash
./gradlew assembleDebug
```

### Build Signed Release APK
1. Open the project in Android Studio.
2. Go to **Build** > **Generate Signed Bundle / APK...**
3. Select **APK** > choose your keystore, alias, and passwords.
4. Select the **release** variant and check **V1** and **V2** signatures.
5. Click **Finish**.
